# Rise of Antares — Dedicated Standalone Android Port

Aplikasi Android mandiri khusus untuk game strategi luar angkasa legendaris **Rise of Antares** (HeroCraft).
Mengeksekusi 100% bytecode Java ME asli dari file  secara langsung pada Android ART.

---

## CARA MEMBUAT (BUILD) APK TANPA PC (CUKUP PAKAI HP ANDROID)

Anda tidak memerlukan laptop atau PC dan tidak perlu menginstall Android Studio!
Gunakan **GitHub Actions** yang sudah kami siapkan di dalam folder .

### Langkah-langkah:
1. **Buat Akun / Buka GitHub di Browser HP**:
   - Buka  lewat Google Chrome di HP Anda.
2. **Buat Repository Baru**:
   - Klik ikon **+** lalu pilih **New repository**.
   - Beri nama:  (pilih Public).
3. **Upload File Proyek Ini**:
   - Di halaman repository baru Anda, klik tombol **"uploading an existing file"**.
   - Upload seluruh isi folder yang ada di dalam zip ini (atau ekstrak zip di HP, lalu upload file dan foldernya).
   - Klik **Commit changes**.
4. **GitHub Otomatis Melakukan Build APK**:
   - Buka tab **Actions** di bagian atas repository GitHub Anda.
   - Anda akan melihat workflow bernama **"Build Rise of Antares Standalone APK"** sedang berjalan otomatis (ikon lingkaran berputar).
   - Tunggu sekitar 2-3 menit sampai muncul tanda centang hijau ✅.
5. **Unduh File APK Langsung ke HP**:
   - Klik pada proses build yang selesai tersebut.
   - Di bagian bawah (Artifacts), klik **"RiseOfAntares-Standalone-APK"**.
   - File APK akan otomatis terunduh ke HP Anda!
6. **Pasang (Install)**:
   - Buka file APK di HP Anda, pilih **Install**.
   - Selamat bermain Rise of Antares secara offline dan mandiri!
